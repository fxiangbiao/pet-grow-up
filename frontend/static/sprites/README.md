# 精灵素材目录

将 AI 生成的宠物精灵 PNG 图片放入对应学科目录：

```
sprites/
├── chinese/
│   ├── basic.png     小书仙 (128x128 以上)
│   ├── mid.png       诗灵
│   └── advanced.png  文圣
├── math/
│   ├── basic.png     智慧猫
│   ├── mid.png       数学龙
│   └── advanced.png  逻辑神
└── english/
    ├── basic.png     小巫师
    ├── mid.png       魔法鸦
    └── advanced.png  大魔导师
```

## 格式要求
- PNG 透明背景
- 建议 128x128 ~ 256x256
- 统一画风

## 素材来源
推荐 AI 工具：aipet.dev（免费像素风宠物精灵生成器）
